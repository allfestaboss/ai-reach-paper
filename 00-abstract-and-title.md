## Abstract

Benchmarks are known to contain incorrect ground truth, and models are already
used to find it. Those results concern **sparse annotation errors** attached to
individual instances, located by statistical methods or by re-annotation. We
report a class they do not reach: **systematic errors in the program that
derives a reference solution**, which displace every case on the same code path
in the same direction. There is then no correct majority for statistical
detection to work against, and re-annotation reproduces the error whenever the
re-annotator follows the same specified procedure.

Such an error is also invisible to the benchmark's own machinery. A grader
compares a submission to the reference; calibration recomputes the reference
along its specified procedure; adversarial cases are generated by corrupting the
reference. All three are functions of the reference solution, and **none can
detect an error in it.**

We report evidence from eight benchmarks — 33 tasks across civil and
architectural CAD, quantity surveying, geotechnical assessment, mechanical
tolerancing, building information modelling, customs classification and tax law
— built to a single design in which the inputs, the procedure and the reference
solutions are all drawn from national standards and administrative rulings
rather than authored by us. Fifteen defects were found on the examination side
rather than in the answers. **Fourteen of the fifteen were located by the
solvers**, which hold the raw inputs but not the answer key; our own calibration
and adversarial suites found one. In the sharpest case, a reference solution
integrated a geotechnical index below the bottom of the borehole, so that
60 percent of one reported value came from depth that was never drilled. It
passed the grader, passed calibration against hand computation — which repeated
the same integration bounds — and passed a twelve-case adversarial suite, every
member of which was generated from the reference and therefore inherited them.

**One further defect was reachable by neither detector.** A graded question
scored five fields that the task statement never mentioned, so no solver could
report their omission, and the reference was not itself wrong, so no check
flagged it. It appeared only as a deduction shared by all six runs of a
replication commissioned to measure something else. Varying the two disclosure
routes independently across three successor tasks that share the reference byte
for byte shows that **either route alone restores full agreement**: the score was
a property of the examination, not of the solvers.

**A third was reachable by none of these.** A grader awarded full marks to a
submission that had read nothing — every real run scored below it — because an
adversarial suite generated by perturbing the reference never probes submissions
far from the reference. No solver could report it, since no solver produces such
a submission; replication could not surface it either, because the six runs
shared the ceiling below the degeneracy rather than the degeneracy itself. It
was found by an outside reading of the method, and that benchmark's result was
withdrawn. Checks, solver reports, replication and external review have
complementary blind spots, and a design resting on any one of them is not
covered.

**A fourth kind was introduced by us while repairing the second.** The note
written to document a task-statement defect printed the answers to four of the
repaired task's thirteen questions; all three solver runs reported it. Auditing
the whole series for the same fault then found it in two further benchmarks that
no solver had flagged — a supplied format description reproducing four rows of
its own reference, and worked examples that were themselves graded answers.
During one frozen run we also became the defect ourselves, misreading a slow
transport as a broken one and instructing two running solvers to truncate; the
one that complied lost six questions, and the one that refused reported the
misdiagnosis.

The same design lets us measure how far three known effects vary across
domains, holding the procedure fixed. Supplying the governing material moves a
drawing-generation task from 25 to 97 out of 100 — a figure we now report with
one qualification rather than two, since the unsupplied arm's failure does not
replicate (26, 26 and 92 over three runs, the spread turning on one binary
guess), while the supplied material's four disclosed reference rows turned out
not to carry the score: re-issued with them removed and the explanation intact,
the supplied arm scored 100 in all three runs — while in customs
classification enlarging it from 0.81 to 4.4 million characters leaves all 61
answers unchanged. Scores saturate while cost does not: in three domains
replicated at n = 3 per configuration, scores tied while token consumption
separated by 2.11x, 1.49x and about 4x, the first two at 15.6 and 13.9 pooled
standard deviations and the third under a weaker control. In
one of the two the cheaper configuration in tokens is the more expensive one in
wall-clock time, so a single cost column cannot rank them. Repeated under
identical conditions,
the fraction of cases whose answer changes every time ranges from 0 to 82
percent — and in half of the unstable cases the number of correct answers is
identical across runs while the set of answers is not, a pattern that
success-rate reliability metrics cannot express.

All eight benchmarks, their reference solutions, their defect records and their
run logs are released under permissive terms with persistent identifiers.

## Abstract — 投稿版（arXiv の1,920文字以内）

Benchmarks contain incorrect ground truth, and models are used to find it. That
work concerns sparse annotation errors on single instances. We report a class it
does not reach: systematic errors in the program deriving the
reference, which displace every case on one code path identically. No correct majority
remains for statistical detection, and re-annotation along the same procedure
reproduces it. It is equally invisible to the benchmark's own machinery:
grader, calibration and adversarial cases are all functions of the reference, so
none detects an error in it.

Evidence: 8 benchmarks, 33 tasks across CAD, quantity surveying, geotechnics,
tolerancing, BIM, customs classification and tax law, built to one design whose
inputs, procedure and references come from national standards. Fifteen
defects were found on the examination side, not in the answers; fourteen by the
solvers, which hold the inputs but not the answer key. In the sharpest, a
reference integrated a geotechnical index below the borehole bottom, putting 60
percent of a value in undrilled depth; it passed the grader, calibration to zero
difference, and twelve adversarial cases. Two further kinds reached no solver: a scored
field the task never specified, and a grader giving full marks to a submission
that read nothing. A fifth we introduced, in a note on
another; auditing the series found two more.

The same design measures how far three documented effects vary by domain.
Supplying the governing material ranges from moving a task 25 to 97 out of 100
to changing none of 61 — the first qualified, as that arm's failure does not
replicate; the material's disclosed reference rows proved not to matter. Where scores tie, cost
does not: across three domains, tied scores came at token ratios of 2.11x, 1.49x
and about 4x. Answers change under identical repetition in 0-82 percent of cases. All benchmarks and defect records carry DOIs.
